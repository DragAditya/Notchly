# Code of Conduct

## Our standard

Notchly is a technical open-source project. Everyone should be able to participate without harassment or hostility.

Examples of expected behavior:

- Discuss code and decisions directly, with evidence and reproduction steps.
- Assume good faith while still being precise about bugs and risks.
- Give credit for ideas, code and reports.
- Respect different experience levels and communication styles.

Examples of unacceptable behavior:

- Personal attacks, insults, threats or sustained disruption.
- Harassment based on identity, including race, ethnicity, nationality, gender, sexual orientation, disability, age or religion.
- Publishing private information without permission.
- Deliberately submitting malware, hidden telemetry or stolen credentials.

## Scope

This policy applies to the repository, issues, pull requests, discussions and any project space managed by the maintainers.

## Enforcement

Maintainers may edit or remove comments, close issues and pull requests, or block accounts when behavior violates this policy. Enforcement decisions should be proportionate and focused on keeping the project usable.

To report a conduct problem, contact the maintainer privately through [DragAditya's GitHub profile](https://github.com/DragAditya). Reports will be handled as confidentially as practical.

## Attribution

This is a project-specific code of conduct, not a copy of a standard template. It is intentionally short so it can be applied consistently.
