# Code signing

Notchly's Windows installers are currently **unsigned**. Windows SmartScreen may
show a warning on first launch, and some users stop there. This is the highest
friction point in the install flow.

## Recommended: SignPath Foundation

[SignPath Foundation](https://signpath.org/) provides free code signing for
open-source projects. Notchly is GPL-3.0-or-later and builds from public GitHub
Actions, so it is a good fit.

1. Apply to SignPath Foundation with the Notchly repository URL, the GPL-3.0
   license, and a short description of the release workflow.
2. After approval, add the SignPath secrets to the repository:
   - `SIGNPATH_API_TOKEN`
   - `SIGNPATH_ORGANIZATION_ID`
   - `SIGNPATH_PROJECT_SLUG`
   - `SIGNPATH_SIGNING_POLICY_SLUG`
   - `SIGNPATH_ARTIFACT_CONFIGURATION_SLUG`
3. Sign the NSIS `setup.exe` and the MSI after `tauri build`, before the release
   workflow uploads them.
4. Keep the Tauri updater `.sig` files. They are generated by Tauri's updater
   key and are separate from the Windows Authenticode signature.

### Application notes

Use these details when applying:

- Project: Notchly
- Repository: <https://github.com/DragAditya/Notchly>
- License: GPL-3.0-or-later
- Build system: GitHub Actions, Tauri v2, Windows x64
- Artifacts: NSIS `setup.exe` and MSI
- Release workflow: `.github/workflows/release.yml`
- Signing scope: tagged release artifacts built from `main`

## Alternative: commercial certificate

An OV or EV code-signing certificate from a public CA also works. Use a cloud
HSM or hardware token, sign the setup EXE and MSI with `signtool`, and timestamp
the signatures with a public timestamp server.

Tauri can run a signing command during the bundle step through
`bundle.windows.signCommand`, or the release workflow can sign the finished
artifacts before uploading them.

## Until signing is available

- Keep `SHA256SUMS.txt` in every release.
- Keep the SmartScreen explanation in the README.
- Offer the portable ZIP as an alternative to the installer.
- Ask users to verify the SHA-256 hash before running an unsigned build.
